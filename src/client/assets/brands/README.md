# Brand icons

The SVG files in this directory are the colour marks from
[`@lobehub/icons-static-svg`](https://www.npmjs.com/package/@lobehub/icons-static-svg) 1.95.1,
which is published under the MIT licence. They are vendored here so the app can ship a curated set
without adding the whole icon package, and each file is used only to identify the vendor or model it
belongs to. Product names and logos are trademarks of their respective owners.
